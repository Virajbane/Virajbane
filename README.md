# 🚀 Featured Projects:

### 🧠 Adaptive-RAG — Enterprise Multi-Agent RAG Platform
Architected a 6-agent pipeline (Rewriter, Planner, Tool, Grader, Answer, Critic) orchestrated with LangGraph, with deterministic validation and routing safeguards on top of each LLM call. Fused Qdrant dense vector search and BM25 keyword search via Reciprocal Rank Fusion, refined with a Cross-Encoder reranker. Migrated PDF ingestion to Docling for structure-aware parsing, boosting retrieval **Recall@6 from 33% to 100%** and **MRR from 0.111 to 0.778** on a golden-set benchmark, while a Redis caching layer **cut repeat-query latency by 93% (28s → 2s)**. Built a Ragas-based evaluation harness (30-question golden set) that surfaced and fixed 3 production bugs.

### 🗄️ AI DB Agent — Universal Database Natural Language Interface
Full-stack NL-to-query interface spanning 5 database systems (MongoDB, PostgreSQL, MySQL, Redis, Supabase) using FastAPI, Next.js, and Ollama (Qwen2.5-Coder 7B). Supports multilingual queries (English, Hindi, Marathi) via hybrid intent classification, with schema-aware, SQL-injection-safe query generation. Cut Ollama cold-start latency from ~3.5 min to ~12s warm response (94% reduction).

### 🎓 EDU.AI — AI-Powered Classroom Learning Platform
Built at Mumbai Hack 2024 (Guinness World Record–recognized hackathon) — features lecture summarization, transcript analysis, and keyframe extraction via Python ML microservices, integrated with Next.js, Tailwind, Supabase, Prisma, and Google OAuth. Delivers personalized study routines and real-time learning analytics.

### 🧩 Resume–Job Matcher — Fine-Tuned NLP Model
Fine-tuned BERT (110M params) on resume–job description pairs for semantic similarity and job-fit scoring, using a `Resume [SEP] Job Description` classification pipeline with softmax-based probability scoring — going beyond keyword matching. Published on Hugging Face Hub.

### ⚡ AI Automation Agents (n8n)
Built 2 n8n automation agents: a **JD → Resume Generator** that tailors a resume to a job description using an LLM and exports a formatted PDF, and a **JD Application Tracker** that scores job fit with Gemini and auto-logs results to Google Sheets.
