### `$ ls -la featured-projects/`

<details open>
<summary><b>🧠 Adaptive-RAG — Enterprise Multi-Agent RAG Platform</b></summary>
<br>

Architected a 6-agent pipeline (Rewriter, Planner, Tool, Grader, Answer, Critic) orchestrated with LangGraph, with deterministic validation and routing safeguards on every LLM call. Built a hybrid retrieval engine fusing Qdrant dense vector search with BM25 keyword search via Reciprocal Rank Fusion, refined with a cross-encoder reranker. Migrated PDF ingestion to Docling for structure-aware parsing, and built a Ragas-based evaluation harness (30-question golden set) that surfaced and fixed 3 production bugs.

| **Stack** | Python, LangGraph, FastAPI, Qdrant, Redis, Docling, Ragas, JWT |
